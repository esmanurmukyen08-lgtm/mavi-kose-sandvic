# Mavi Köşe Sandwich Website 🥪

A responsive restaurant website designed for Mavi Köşe Sandwich in Göztepe, İzmir.

## Features

- Responsive design
- Navigation bar
- Hero section
- Popular sandwich cards
- About us section
- Location and contact information
- Google Maps integration
- Order buttons
- Mobile-friendly layout

## Technologies

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## Project

This project was created to practice HTML and CSS and to improve my web design skills.
